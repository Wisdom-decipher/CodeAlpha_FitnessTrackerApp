# CodeAlpha_FitnessTrackerApp

A fitness tracking app built for the CodeAlpha App Development Internship (Task 3).

## Features

- Log daily activities: type, duration, calories burned, and steps (optional)
- Edit or delete any logged entry
- Dashboard summary: today's steps, active minutes, calories, and current day-streak
- Editable daily step goal with a live progress bar
- 7-day calories bar chart (via Chart.js)
- Data persists locally via browser localStorage
- Dark mode toggle
- Clear-all-data option with confirmation
- Clean, responsive, mobile-friendly UI

## How to run

1. Clone this repo
2. Open `index.html` in your browser (or use the VS Code "Live Server" extension)

No build steps or backend required: pure HTML, CSS, and JavaScript, with Chart.js loaded from a CDN for the weekly chart.

## Tech stack

HTML5, CSS3, vanilla JavaScript, browser localStorage, Chart.js.
